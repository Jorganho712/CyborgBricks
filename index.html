🤖 Blocos Pybricks — Missões

Arraste (ou clique) os blocos para montar cada missão. O código Python é gerado ao lado.

Código das missões

Cole no lugar das funções missao_1 a missao_6 do seu main.py (o resto do código continua igual).

Funções extras — cole uma vez no main.py, antes das missões

Os blocos novos usam estes nomes de objetos: hub, robot, left, right, C, D, cor1, cor2, dist, forca. Se no seu main.py forem outros, renomeie lá ou troque nas funções.
